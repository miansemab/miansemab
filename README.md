## About

I'm **M. Semab Ilyas**, a Computer Science student focused on **Machine Learning, AI, and software development**.

I use Python to explore data, prepare datasets, train machine learning models, and evaluate their performance. Alongside ML, I build web applications and backend systems, with an interest in bringing intelligent features into useful, reliable products.

- **Machine Learning:** data analysis, preprocessing, classification, model training, and evaluation.
- **AI:** exploring LLM applications, Retrieval-Augmented Generation (RAG), and Agentic AI workflows.
- **Development:** Python, Django, React, Next.js, APIs, and database-driven applications.
- **Approach:** learn by building, evaluate carefully, and improve through iteration.
